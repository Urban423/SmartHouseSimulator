# Smart House Simulator

A **Smart House Simulator System** built on a custom engine, designed to emulate smart home devices, automation, and sensor interactions in a virtual environment. This system allows developers and users to simulate, monitor, and test smart house scenarios without needing real hardware.

---

## Features

- **Device Simulation**: Supports virtual devices such as lights, thermostats, door locks, cameras, and sensors.  
- **Automation**: Customizable rules and triggers for automated device interactions.  
- **Real-time Monitoring**: Observe device states and events in real time.  
- **Custom Engine**: Fully built on a custom engine optimized for performance and flexibility.  
- **Extensible**: Easily add new device types or automation rules.  

---

## System Architecture

The system consists of the following modules:

1. **Engine Core**  
   - Handles simulation, device states, and event scheduling.  
   - Provides APIs for device management and automation.  

2. **Device Module**  
   - Contains virtual devices and their behaviors.  
   - Supports adding new device classes dynamically.  

3. **Automation Module**  
   - Rule engine that triggers actions based on conditions or events.
